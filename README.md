# 📈 주식 AI 상승하락 알리미

관심 종목을 등록하면 **AI(로지스틱 회귀)가 다음 거래일 상승/하락을 예측**하고,
장중 가격이 설정한 변동률(±1~5%)을 넘으면 **브라우저 알림**을 보내주는 웹 앱입니다.

## 기능

- 🎯 **전략별 맞춤 추천** — 단타 / 종가배팅 / 스윙 / 중장기 중 투자 전략을 선택하면,
  전략의 시간축(1일/5일/20일)으로 AI 모델을 다시 학습하고 전략이 실제로 보는 지표
  (단타: 장중 모멘텀·수급, 종가배팅: 마감 강도·거래량, 스윙: 중기 추세·RSI,
  중장기: 60일선 방향)로 **매수 우위 / 관망 / 회피·매도 우위**를 근거와 함께 보여줍니다.
  수급 이탈 시 모든 전략에서 감점되는 공통 원칙을 적용합니다.

- 💧 **수급 중심 판단** — "상승은 수급이 따라올 때 붙는다"는 원칙으로,
  OBV(누적 거래량 매집/분산), MFI(자금 흐름 지수), 상승일/하락일 거래량 비율을
  합쳐 **수급 점수(0~100)**를 계산합니다. 수급이 유입(60점 이상)될 때만 상승으로
  판단하고, 수급이 이탈(40점 이하)하면 모델이 상승 신호를 내도 하락 우려로 표시합니다.
- 🤖 **AI 예측** — Yahoo Finance 2년치 일봉 데이터로 기술 지표 + 수급 지표 14개를
  계산하고, 브라우저에서 직접 로지스틱 회귀 모델을 학습해 다음 거래일 상승 확률을
  보여줍니다. 백테스트 정확도도 함께 표시합니다.
- 🔔 **급등락 알림** — 페이지가 열려 있는 동안 1/5/10분 간격으로 가격을 감시하다가
  전일 대비 변동률이 기준을 넘으면 브라우저 알림 + 알림 기록을 남깁니다.
- ⚡ **장중 수급 유입 감지** — 5분봉 기준으로 (1) 최근 15분 거래량이 당일 평균의
  2.5배 이상 급증하며 가격 상승 동반, 또는 (2) 장중 OBV가 하락에서 상승으로 전환되면
  "수급 유입 감지" 알림을 보냅니다 (종목당 하루 1회). 일봉 수급 점수가 55점 이상인
  종목이면 "최근 매집 흐름과 일치 🔥"를 함께 표시합니다.
- 📱 **텔레그램 푸시 (선택)** — @BotFather로 만든 봇 토큰과 Chat ID를 설정하면
  알림을 휴대폰 텔레그램으로도 보냅니다. 토큰은 브라우저 localStorage에만 저장됩니다.
  (단, 탭이 열려 있는 동안 발생한 알림만 전송됩니다)
- 📋 **관심 종목 관리** — localStorage에 저장되어 다시 방문해도 유지됩니다.

## 종목코드 입력법

| 시장 | 형식 | 예시 |
|---|---|---|
| 코스피 | 종목코드.KS | `005930.KS` (삼성전자) |
| 코스닥 | 종목코드.KQ | `247540.KQ` (에코프로비엠) |
| 미국 | 티커 그대로 | `AAPL`, `TSLA`, `NVDA` |

## 구조

```
index.html    UI
style.css     스타일

```

```bash
npm i -g vercel
vercel dev
```
